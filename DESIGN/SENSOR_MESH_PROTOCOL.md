# 传感器 Mesh 透传协议说明

本文档描述 `chat` 工程中经 Bluetooth Mesh 模型透传的**应用层二进制帧**格式，实现见 `include/sensor_mesh_protocol.h` 与 `src/sensor_mesh_protocol.c`。

---

## 1. 概述

| 项目 | 说明 |
|------|------|
| 用途 | 终端设备向指定 Mesh 地址上报压力、温度、生命体征，可选 50 点心电波形 |
| 命令字 | 固定 `0xC55C`（`CMD_MESH_DATA_HEAD`），帧内为高字节在前 |
| 字节序 | 多字节整数除特别说明外：**16 位地址与 CRC 为低字节在前（小端）**；命令字在帧内按**大端**写入（高字节先） |
| 校验 | **Modbus CRC-16**（多项式 0xA001，初值 0xFFFF），覆盖从帧首到**序号字节（含）**的全部字节；CRC 在帧尾以**低字节在前**存储 |

编译选项 `CONFIG_CHAT_SENSOR_PACKET_INCLUDE_WAVEFORM`：

- **关闭**：仅基座载荷，整帧约 **45 字节**。
- **开启**：基座 + 50 点 ×12 bit 心电波形，整帧约 **120 字节**。

---

## 2. 帧结构（线性布局）

从偏移 0 开始依次为：

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 2 | `cmd` | 固定 `0xC5`、`0x5C`（即命令字 0xC55C） |
| 2 | 1 | `datalen` | 见下文 **§2.1** |
| 3 | 2 | `dst` | 目标 Mesh 单播地址，小端 |
| 5 | 2 | `src` | 源 Mesh 单播地址（发送端 `bt_mesh_primary_addr()`），小端 |
| 7 | `P` | `payload` | 传感器载荷，`P` = 35 或 110，见 **§3** |
| 7+P | 1 | `seq` | 包序号，**1 字节**，发送端自增，256 溢出回绕，用于丢包检测 |
| 8+P | 2 | `crc` | Modbus CRC-16，**小端**（低字节在前） |

**整帧长度** = `2 + 1 + 2 + 2 + P + 1 + 2` = **10 + P** 字节。

- 仅基座：`P = 35` → **45 字节**。
- 带波形：`P = 110` → **120 字节**。

### 2.1 `datalen` 字段

```text
datalen = P + 2 + 2 + 1 = P + 5
```

即：**目标地址(2) + 源地址(2) + 序号(1) + 载荷(P)** 的字节数之和。  
**不包含** 命令字、`datalen` 自身以及 **CRC**。

> 注意：`datalen` 为 `uint8_t`，若将来载荷增大导致该和超过 255，需协议升级。

---

## 3. 载荷 `payload`（`memcpy` 内存布局）

载荷为 **packed 结构体**，按 **小端** 解释多字节逻辑字段（如 vitals 打包字）。

### 3.1 公共基座 `SensorPacketBase_t`（35 字节）

前 **32 字节**在内存中连续存放为 `uint8_t[32]`，但**语义上分为两类**（与旧网关 182 字节帧一致：前 28 路压力垫 + 后 4 路温度），**不可**再全部当作压力 ADC 用同一套换算。

| 偏移（载荷内） | 长度 | 字段 | 说明 |
|----------------|------|------|------|
| 0 | 28 | `pressure[28]` | **压力垫** 28 路，每字节 0~255。源数据为 SAADC `int16`，编码：`raw≤0→0`，`raw≥4095→255`，否则 `uint8_t(raw >> 4)` |
| 28 | 4 | `temperature[4]` | **温度** 4 路，每字节 0~255，**独立编码**，与压力通道不同。推荐约定：**物理量为整数摄氏度**（如 36 表示 36℃）；需要与旧协议「0.1℃ 整数」对齐时，上位机可做 `display_tenths = raw * 10`（即显示为 `display_tenths / 10.0` ℃）。若固件改为直接发送 **0.1℃ 整数**（0~255 表示 0.0~25.5℃ 等），则应由上位机按实现约定**直接使用 `raw` 作为 tenths**，不再乘 10。 |
| 32 | 3 | `vitals[3]` | 24 bit **小端** 打包，见 **§3.2** |

> **勘误说明**：此前文档将 32 字节统称为 `pressure[32]`，易误解为 32 路均为压力；实际 **索引 28~31 为温度通道**，仅索引 **0~27** 为压力垫（与 `pressure[28]` 及 `temperature[4]` 布局一致）。

### 3.2 `vitals[3]`（24 bit 小端）

合成为一个 24 位无符号数 `pack`（`vitals[0]` 为最低字节）：

```text
pack = breath & 0x1FF
     | ((heart & 0x7FF) << 9)
     | ((posture & 0xF) << 20)
```

| 域 | 位宽 | 含义 | 取值说明 |
|----|------|------|----------|
| `breath` | 9 | 呼吸相关 | 0~511，发送前饱和到 511 |
| `heart` | 11 | 心率 | 0~2047；设备内存中为 **bpm×10**（十分位心率），发送前饱和到 2047 |
| `posture` | 4 | 睡姿枚举 | 见 **§4**，发送前取低 4 bit |

解码示例（伪代码）：

```c
uint32_t pack = vitals[0] | ((uint32_t)vitals[1] << 8) | ((uint32_t)vitals[2] << 16);
uint16_t breath = pack & 0x1FF;
uint16_t heart  = (pack >> 9) & 0x7FF;   /* 实际心率×10 */
uint8_t  posture = (pack >> 20) & 0xF;
```

### 3.3 可选：心电波形 `SensorPacketWithWave_t`（110 字节）

在基座 **之后** 紧接 **75 字节**：

| 偏移（载荷内） | 长度 | 字段 | 说明 |
|----------------|------|------|------|
| 0 | 35 | `base` | 同 **§3.1** |
| 35 | 75 | `heart_waveform[75]` | 50 个采样点，每点 **12 bit**（有效 0~4095），见 **§3.4** |

### 3.4 12 bit 波形打包（75 字节 = 50×12 bit）

- 采样顺序与缓冲中**时间顺序**一致：旧→新或按实现定义的环形缓冲快照（设备端取最近 50 点）。
- **每 3 字节存 2 个采样**（`s0`、`s1` 均为 12 bit，发送前掩码 `& 0x0FFF`）：

```text
b0 = s0 & 0xFF
b1 = (s0 >> 8) & 0x0F  |  ((s1 & 0x0F) << 4)
b2 = (s1 >> 4) & 0xFF
```

解码示例（对第 `k` 组，`k = 0..24`，对应样本 `2k`、`2k+1`）：

```c
int o = k * 3;
uint16_t s0 = (uint16_t)(buf[o+0] | ((buf[o+1] & 0x0F) << 8));
uint16_t s1 = (uint16_t)((buf[o+1] >> 4) | (buf[o+2] << 4));
```

## 4. 睡姿枚举 `PostureType`

与 `vitals` 中 `posture` 域一致（4 bit，仅用到下列值）：

| 值 | 符号名 | 说明 |
|----|--------|------|
| 0 | `POSTURE_NONE` | 无人 |
| 1 | `POSTURE_SUPINE` | 仰卧 |
| 2 | `POSTURE_SIDE_LEFT` | 左侧卧 |
| 3 | `POSTURE_SIDE_RIGHT` | 右侧卧 |
| 4 | `POSTURE_DONG` | 体动 |
| 5 | `POSTURE_WARNING` | 体位异常 |
| 6 | `POSTURE_UNPRESS` | 异常（可能未按压等） |

---

## 5. CRC 计算

- 算法：**Modbus CRC-16**（与 `src/utils.c` 中 `ModbusCRC_CheckTable` 一致）。
- 输入：从帧第 0 字节到 **序号 `seq` 最后一个字节**（含），长度为 `8 + P`（即不含 CRC 的整帧长度）。
- 输出：16 位 CRC，在帧中先写**低 8 位**，再写**高 8 位**。

接收端校验步骤：对前 `8+P` 字节计算 CRC，与末尾 2 字节比较（小端拼成 16 位）。

---

## 6. 版本与兼容性

- 协议与固件中的 `BUILD_ASSERT(sizeof(SensorPacketBase_t)==35)`、`sizeof(SensorPacketWithWave_t)==110` 绑定；若修改结构体，需同步更新本文档与上位机解析。
- Mesh 传输层（分段、加密等）由 Bluetooth Mesh 栈处理，本文仅描述**应用层**透明负载。
